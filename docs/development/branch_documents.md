# Branch Documents

Every branch has one living document `docs/branch-docs/<branch>.md` (a `/` in the branch name becomes `--`).
The title is the unchanged branch name. It records what changed, why, and decisions that must survive the branch.
Write it in English. The `PR process` check fails without it.

```markdown
# <branch-name>

## Goal

## Tickets

## Scope

## Decisions

## Alternatives Considered

## Verification
```
