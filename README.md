# testrepo

Hello-world app for the software factory proof of concept. It mirrors the Digital Grid conventions
(issue forms, labels, board lanes, CI checks, branch documents) so agents and humans can be tried on the
same process without touching the real repository.

```bash
corepack enable
yarn install
yarn dev          # http://localhost:3000, /api/hello
yarn check        # typecheck, format, unit tests
```

Process: [docs/development/process.md](docs/development/process.md).
